# 射箭计分宝 — 改进待办

状态：1.4.7 已发布；当前内部测试版为 1.4.7-beta3。
本文记录已知逻辑缺口、体验优化和后续想法；完成或调整范围时更新本文。

## P0 — 逻辑正确性

- **补全自动重连策略。** 当前只重试最后一次保存的 SSID。目标：断线先尝试所有已保存 SSID 一次；全失败后只重试最后 SSID，30s→60s→2min→5min→10min 退避；每第三次尝试全部列表；不扫描；连上即停；手动扫描随时可用。
- **自动训练检测加超时。** 8～10 秒未返回按“语音不可用”处理并进入训练，避免卡在检测页。
- **加载时强制语音/滚动互斥。** 旧 NVS 可能两个都开；应用设置时强制关闭一个。
- **后台任务不要写 NVS。** 自动检测结果已交回主任务，后续 Wi-Fi/语音改动继续遵守。

## P1 — 体验优化

- **语音失败显示完整原文。** 录入页底部只有一行，长文本会被截断；建议两行或可滚动详情。
- **语音等待自适应。** 短句保持 1 秒快速失败，长句延长到 1.5～2 秒。
- **倒计时片段统一。** 系统/小豆都是 600ms，但语速和尾部静音仍不同，7 仍有截断感；建议统一语速重新生成或归一化。
- **已保存网络管理。** 增加“清除已保存网络”和“已保存”标识，否则旧错误密码无法清理。
- **密码页可发现性。** 双击连接逻辑正确但不够直观，可增加明确的“连接”状态或提示。

## P2 — 维护

- **诊断页语音状态。** 目前只是上次握手结果；增加时间戳和“立即检测”按钮。
- **主机/CI 测试覆盖。** 12 行设置、设置 v11、Beta 子菜单、自动检测结果应用、Wi-Fi 密码流程、保存网络回退。
- **发布纪律。** Beta 只发 GitHub prerelease；验证稳定后再提交社区。

## 真实使用场景 — 待处理（1.4.8）

- 训练数据没有检查点；断电、死机、误退会丢掉整场训练。需要会话恢复或定期保存草稿。
- 自动训练会覆盖用户显式选择的语音/滚动。需要明确“自动模式优先”，或尊重手动选择并提示本次覆盖。
- 设置保存语义不一致：主设置长按保存，Beta 子菜单切换后要再回设置保存才生效。建议离开 Beta 时自动保存或显示未保存标记。
- 自动重连可能在语音报靶或计时训练中运行。语音/PTT 或计时进行时应暂停重连。
- 已保存网络连接失败时，如果用户已改选其他网络，可能被带回上一个网络的密码页。pending 需按 SSID/行号匹配。
- 音频竞争：倒计时、提示音、语音识别可能重叠。应串行化音频，或在倒计时期间禁止 PTT。
- 时间固定 UTC+8，无夏令时/时区；NTP 可能覆盖手动时间且无提示；时钟页字段不会实时刷新。
- 电源：无低电量警告和优雅关机；瞄准时可能自动熄屏；断电可能打断 NVS 写入。
- 安全：API Key 明文存 NVS；配网页没有访问控制。
- 可恢复性：重连任务在 connect 调用内部有短暂不可取消窗口；历史不能修改/删除单组；语音失败后没有改按键的快捷入口。
